# Data

450 tasks total: 60 real (Nextflow traces) + 90 (WfCommons) + 300 (synthetic).

- `nextflow_traces/` — 10 trace files from nf-core/rnaseq on KU HPC
- `wfcommons_traces/` — 15 WfCommons RnaseqRecipe JSON files
- `synthetic/` — 300 tasks generated with lognormal distributions
- `training_data.csv` — combined dataset used for training
